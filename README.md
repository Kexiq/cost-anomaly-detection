# Cost Anomaly Detection

## О проекте

Проект направлен на выявление аномальных значений в данных о себестоимости и подготовке данных для дальнейшего анализа.

Цель — автоматизировать поиск потенциально некорректных значений, которые могут искажать результаты финансовой аналитики.

## Основные возможности

- Анализ данных о расходах с использованием Python.
- Выявление потенциальных аномалий с помощью статистического метода IQR (межквартильного размаха).
- Применение нескольких проверок для обнаружения нетипичных значений.
- Использование исторических данных и бизнес-правил для анализа отклонений.
- Корректировка выявленных аномальных значений.

## Используется

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft Excel


## Результаты анализа

Алгоритм был протестирован на демонстрационных данных.

- Проанализировано 32 записи.
- Выявлено 12 потенциальных аномалий.
- Подтверждено 12 аномалий.
- Скорректировано 12 значений себестоимости.
- Доля скорректированных записей — 37,5%.

Результаты сохраняются в файл `Итого анализ выбросов.xlsx`.

## Структура проекта

- `Усреднение-Copy2.ipynb` — основной алгоритм анализа и корректировки аномалий.
- `Новая таблица.xlsx` — тестовый набор данных.

## Как запустить

1. Установить Python и библиотеки `pandas`, `numpy`, `openpyxl`.
2. Открыть `Усреднение-Copy2.ipynb` в Jupyter Notebook или VS Code.
3. Убедиться, что файл `Новая таблица.xlsx` находится в рабочей папке.
4. Выполнить ячейки ноутбука последовательно.
